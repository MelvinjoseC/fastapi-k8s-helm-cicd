# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this microservice and deployment ecosystem seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not create public GitHub issues** for security-sensitive vulnerabilities.
2. Email the maintainer directly at `165891174+MelvinjoseC@users.noreply.github.com` with the subject `[SECURITY ISSUE] FastAPI K8s`.
3. Include detailed steps to reproduce, proof of concept, and affected components (FastAPI app, Docker image, Helm chart, or Kubernetes manifests).

### Vulnerability Response SLA
- **Initial Response**: Within 24 hours.
- **Triage & Reproduction**: Within 48 hours.
- **Patch Release**: Critical vulnerabilities will be patched within 7 business days.
